# Timer

A countdown timer for the Edge.

- **Start:** tap a preset (1, 3, 5, 10, 15 or 25 minutes by default).
- **Pause and resume:** tap the time. When it's finished, tapping it starts the same time again.
- **−1 / +1:** take off or add a minute, even while it runs. With nothing running, +1 starts a 1-minute timer.
- **Reset:** clears it.
- **When it's done:** the time turns amber and blinks, the widget flashes, and it beeps three times.
- **Restarts:** a running timer keeps going if the dashboard or iCUE reloads the widget.

| Size | Layout |
|---|---|
| S and Wide | The dial on the left, the buttons on the right |
| M and taller | The dial on top, the buttons below |

**Settings:**
- **Presets:** in minutes, separated by commas, up to 8 (for example `2, 5, 30, 60`).
- **Beep when done:** on or off.
- **Accent color.**

It needs no helper and no internet.
